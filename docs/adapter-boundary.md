# System-of-Record Adapter Boundary: CSV Ingest & Staged Payloads

## Operational Context & Sovereign Boundary

TATHYON is a resilient verification and allocation intelligence sidecar. It **does not replace** state and national systems of record (e.g. DVDMS, e-Aushadhi, HMIS). 
- It **never claims** live execution of transfers in government databases.
- Payloads produced for upstream systems are **staged and signed**, awaiting physical custody transfer and official execution by the statutory custodian.
- Inbound data is ingested from standard report exports (CSV / TSV) generated by DVDMS or e-Aushadhi.
- Every ingested record is tagged with provenance (`provenance="CSV_IMPORT"` or `provenance="SYNTHETIC"`).

## 30-Second Audit: What is NOT Connected (The Honest Boundary)

A reviewer or judge can review everything that is **deliberately NOT configured** in this deployment:

| External System / Service | Status | Why Not Configured | The Honest Boundary (What We Do Instead) |
|---|---|---|---|
| **DVDMS Live API** | `NOT_CONFIGURED` | State-level DVDMS lacks an authenticated open REST API for automated mutation; write-access requires statutory custodian custody transfer. | Ingests offline CSV/TSV inventory exports; emits signed, staged dispatch vouchers (`POST /plans/{id}/sor-payload`) for human custodian upload. |
| **e-Aushadhi Live API** | `NOT_CONFIGURED` | National NIC e-Aushadhi deployment operates inside government NICNET with restricted VPN access; automated third-party writes violate security policy. | Ingests standard e-Aushadhi inventory dump columns; formats allocations as e-Aushadhi transfer vouchers awaiting statutory DHO signature. |
| **Google Routes API** | `NOT_CONFIGURED` | Requires proprietary cloud billing and active internet transit in remote tribal blocks (e.g. Bastar) where cellular connectivity is intermittent. | Uses locally hosted Open Source Routing Machine (OSRM) with local OpenStreetMap road topologies, with deterministic Haversine distance fallback. |
| **Google Earth Engine** | `NOT_CONFIGURED` | Dynamic satellite compute pipelines introduce high API latency (15–60s) and vendor lock-in incompatible with district server offline requirements. | Uses static, cached monsoon flood vulnerability layers and precipitation telemetry from Open-Meteo as informational inputs only. |
| **Live Satellite / Drone Imagery** | `NOT_CONFIGURED` | Optical earth observation has 1–5 day revisit latency and cannot resolve indoor pharmacy shelf inventory through facility roofs. | Relies strictly on ground-level physical count attestations (`Attestation`) conducted by human medical officers with strict `attester != custodian` separation. |

## Ingest Schema: DVDMS / e-Aushadhi Export Columns

The CSV ingest engine in `tathyon/adapters.py` supports standard column headers and case-insensitive aliases:

| Canonical Field | Type | Expected DVDMS / e-Aushadhi Aliases | Mandatory | Default / Coercion Rule |
|---|---|---|---|---|
| `facility_id` | `str` | `FacilityCode`, `FacilityID`, `StoreCode`, `store_id` | **Yes** | Trimmed string. Missing raises `MISSING_FACILITY_ID`. |
| `facility_name` | `str` | `FacilityName`, `StoreName`, `facility_name` | No | Defaults to `facility_id`. |
| `district` | `str` | `District`, `DistrictName`, `district` | No | Defaults to `"Unknown"`. |
| `state` | `str` | `State`, `StateName`, `state` | No | Defaults to `"Chhattisgarh"`. |
| `sku` | `str` | `DrugCode`, `ItemCode`, `ResourceSKU`, `drug_code`, `sku` | **Yes** | Trimmed string. Missing raises `MISSING_SKU`. |
| `drug_name` | `str` | `DrugName`, `ItemName`, `GenericName`, `item_name` | No | Defaults to `sku`. |
| `batch_number` | `str` | `BatchNo`, `BatchNumber`, `batch_number`, `lot_no` | No | None if blank. |
| `expiry_date` | `str` | `ExpiryDate`, `ExpDate`, `expiry_date` | No | ISO format if parseable, or None. |
| `reported_quantity` | `float` | `AvailableStock`, `ClosingBalance`, `Quantity`, `stock_qty` | **Yes** | Coerced from numeric strings (e.g. `" 1,250 "` → `1250.0`). Unparseable strings (`"N/A"`, `"error"`) raise `INVALID_QUANTITY` for that row. |
| `consumption_velocity` | `float` | `DailyConsumption`, `ConsumptionVelocity`, `MonthlyConsumption` | No | Coerced float. If `MonthlyConsumption`, divided by 30. Defaults to 5.0 if missing. |

## Fault Tolerance & Error Model

The CSV ingest follows strict batch fault tolerance:
1. **Never Crash the Batch**: A malformed or unparseable row generates a typed `RowValidationError` and is skipped, while all valid rows in the file are processed and returned in `IngestResult.valid_records`.
2. **Typed Error Structure**:
   ```python
   @dataclass
   class RowValidationError:
       row_index: int       # 1-based line number in CSV
       field: str           # Target field ("reported_quantity", "sku", etc.)
       raw_value: Any       # Raw text that caused the error
       error_type: str      # E.g. "INVALID_QUANTITY", "MISSING_FACILITY_ID"
       message: str         # Human-readable diagnostic description
   ```
3. **Quantity Coercion**:
   - Commas stripped: `"2,500"` → `2500.0`
   - Trailing/leading whitespace stripped: `" 100 "` → `100.0`
   - Non-numeric text: `"ten"`, `"N/A"`, `"missing"` → logs `INVALID_QUANTITY`, does not crash.

## Staged System-of-Record (SOR) Payload Boundary

Payloads formatted for upstream government systems (DVDMS voucher, e-Aushadhi dispatch order, FHIR R4 SupplyRequest) have the following non-negotiable metadata attributes:
- `status`: `"READY_FOR_SYSTEM_OF_RECORD"`
- `execution_boundary`: `"PAYLOAD_STAGED_NOT_EXECUTED_EXTERNALLY"`
- `disclaimer`: Explicit statement that Tathyon is an intelligence sidecar and physical transfer requires statutory custodian action.
- `provenance`: `"AUTHORIZED_HUMAN_APPROVAL"`
- `integrity_hash`: Cryptographic SHA-256 seal covering plan ID, total quantity, voucher ID, and approving medical officer credentials.
